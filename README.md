# Simple BarCode

![BarCode Example](https://i.postimg.cc/tCLT35qs/image.png)

Essa é uma implementação de um gerador de código de barras em 1D, especificamente o tipo Code 128. O projeto foi criado com o objetivo de aprender sobre o funcionamento desse padrão de codificação, sem utilizar bibliotecas externas que já façam esse trabalho.


---

- [Como funciona o Code 128](https://bitabit.pages.dev/dev-hour/posts/como-cod128-funciona/como-cod128-funciona/)
